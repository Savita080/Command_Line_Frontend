# 🏛️ University Club Management System - Frontend

A modular Webpage with **React**, **Vite**, and **React Router DOM**, designed to connect directly to the **Node.js/Express Backend**. The portal enforces strict **Role-Based Access Control (RBAC)** across four dedicated user workspaces: **Students**, **Club Heads**, **Faculty Mentors**, and the **Dean of Student Welfare (DSW)**.

---

## 👥 Role Workspaces & Feature Scope

| Role | Workspace Features |
| :--- | :--- |
| **🎓 Student** | Explore all university clubs, check hierarchy trees, apply for club memberships, track application statuses, and view the central campus events calendar. |
| **👑 Club Head** | Access assigned club analytics, manage rosters (promote roles, remove members), review incoming student applications, schedule events, and request event budgets. |
| **🧑‍🏫 Faculty Mentor** | Review club progress, supervise changes, and review club-level event and budget proposals. |
| **🏛️ DSW (Admin)** | Executive campus dashboard, filtered directory across all clubs, approve or deny event budgets.|
